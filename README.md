# Модель фонда оплаты труда (2027 год)

## Запуск
1. Распакуйте архив в отдельную папку.
2. Откройте папку в VS Code.
3. Откройте `index.html` через Live Server или напрямую в браузере.

## Файлы
- `index.html` — структура модели.
- `style.css` — оформление и адаптивная компоновка.
- `script.js` — расчёты, таблицы, графики и интерактивные подсказки.

## Важные расчёты
- Лидоруб получает 1 000 руб. за каждый целевой состоявшийся замер.
- Сумма KPI за замеры рассчитывается автоматически и показана отдельной колонкой в помесячном расчёте.
- В персональной разбивке эта выплата обозначена как «KPI за замер».
- Выплата за замеры включена в переменную часть ФОТ и не дублируется в общей сумме.
- При наведении на столбцы графика ФОТ по месяцам показываются сумма ФОТ и его доля от выручки.
- При наведении на сегмент структуры годового ФОТ показываются сумма и доля соответствующей части.
- При наведении на месяц в сезонном распределении показываются выручка, ФОТ и доля ФОТ от выручки.
